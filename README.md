# JARVIS (stage 1) - Windows

Telegram bot + Ollama + Supabase Postgres. Everything is entered by chatting with the bot.

Run (from PowerShell, inside this folder):

    .venv\Scripts\python.exe -m pip install -r requirements.txt
    .venv\Scripts\python.exe bot.py

Needs a filled-in .env file (copy .env.example to .env).
